# Contributing

1. Add `skills/<skill-name>/SKILL.md` with valid frontmatter (`name` must match the folder).
2. Keep skills focused on Herdr workflows; link to [herdr docs](https://herdr.dev) for CLI facts that change every release.
3. Require `HERDR_ENV=1` when the skill only applies inside a Herdr pane.
4. Update the catalog table in `README.md`.

Do not commit secrets or internal hostnames.
